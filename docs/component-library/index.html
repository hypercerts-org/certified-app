Certified · Component Library

Component Library

A hand-authored, self-contained styleguide for the certified-app primitive library in src/components/ui/. The primitives are TSX and can't be rendered without a build, so every example below is static HTML that mirrors each primitive's real rendered output (matching its actual class names and token usage). All styling is inline; there is no build step, dev server, or network dependency. Toggle the control above to view every example in light and dark.

Fonts: production uses Inter (UI) and Noto Serif via font-headline (headlines). With no network access here, this file falls back to system-ui for body/UI and Georgia, serif for headlines (the documented tail of the headline font stack). Only the glyph shapes differ from production — sizes, weights, and tracking are reproduced exactly.

Monochrome

Near-black primary, warm grays, no brand accent hue. Identity is carried by typography, not color.

Document-like

Serif headlines anchor content like a printed title; Inter handles all chrome. Reads like a notary's ledger.

2px radius

--radius: 2px everywhere; 999px for pills, 50% for circles. Sharp, deliberate edges.

Mobile-first

Every layout is designed for small screens first; desktop is a natural widening of one centered column.

Accessibility-first

Skip-nav, global :focus-visible rings, ARIA roles on tabs/menus/switches, and prefers-reduced-motion support throughout.

Dark mode

Full data-theme="dark" flip: surfaces invert, the primary button inverts so it always pops off the canvas.

Buttons, form controls, and the theme + link primitives.

Button src/components/ui/button.tsx

The canonical button. Four variants (primary / secondary / ghost / destructive) and four sizes (sm / md / lg / icon). Renders a real <button> with press-scale, a --focus-ring outline, and aria-busy while loading. The icon size is a 40×40 square and its discriminated union requires aria-label. Reach for this before any raw <button>.

Dialog family app-dialog · confirm-dialog · delete-record-dialog · form-dialog · bottom-sheet · responsive-dialog · drawer
