03 / Work

Five controlled cuts

Each active phase has one owner and one acceptance boundary. The old path remains available until staging proves the new one; preference persistence is a later follow-up.

Deferred follow-up: this cutover does not add a preference Lexicon, personal-PDS writes, a local preference cache or cross-device synchronization. Evaluator and organization-quality selections remain request inputs only.

04 / Files

Keep the seam narrow

The home feed changes shape. Explore, generic profile queries and the rest of `/api/indexer` remain untouched.
