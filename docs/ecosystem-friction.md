# Ecosystem & Upstream Friction Catalog

Every concrete place where `certified.app` (`v2`) carries workaround code, bypasses an official package, accepts extra latency, or maintains a stopgap because of an upstream gap in the Hypercerts stack, AT Protocol tooling, infrastructure, or UI toolkit.

Use this document alongside `docs/toolkit-gaps.md` to prioritize upstream fixes across the Hypercerts ecosystem. Each item names the exact code that exists today solely because of the gap, and what upstream change lets `certified.app` (and every partner app copying it) delete it.

---

## Top 5 Highest-Leverage Upstream Fixes

Ranked by latency saved + workaround complexity deleted for both `certified.app` and downstream partners:

1. **Verified `handle` + CDN `imageUrl` on API & Feed/Views responses (`TECH-896` + Image CDN)** — deletes `identity.ts` fan-out from every read, cuts ~550 ms cold latency per actor, removes the uncontracted `cdn.bsky.app` dependency, eliminates `AuthorLink` / `ProfileAddress` streaming gymnastics, and allows resolving 404s before streaming.
2. **SDK update/delete writes + arbitrary collection items (`TECH-956`) + npm publish** — unblocks Activity/Project editing and deleting, deletes the 777-line parallel `src/lib/hypercerts/writes.ts` + vendored tarball, and eliminates the non-atomic 2-step `createListWithItem` flow.
3. **API counts, funding summaries, unified actors, and Views-backed timelines/profile feeds (`TECH-944`)** — eliminates 200-page receipt loops, 10-endpoint profile-feed fan-out, N+1 badge holder counts, and dual org+profile fetches.
4. **API data hygiene & real HTTP status codes (`TECH-791`, `TECH-858`)** — re-enables strict XRPC response validation and deletes defensive union parsing + HTTP 500 substring sniffing.
5. **CGS hardening (`app.certified.actor.profile` admin auth, `applyWrites`, group handle/account ops)** — closes a live permission gap and eliminates elevated password sessions for group administration. _(Resolved: `com.atproto.server.getServiceAuth` shipped in `@hypercerts-org/certified-group-service@0.2.0`, deleting `lexicons.json` and `src/lexicons/`.)_
